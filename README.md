# 제주 가을여행 앱 — 설치 안내서

우리 여섯의 제주 2박 3일(2026. 10. 16 – 18) 여행 앱이에요.
일정, 지도 버튼, 사진, 한마디를 한곳에서 보고, 누구나 일정을 바꾸거나 건너뛸 수 있어요.

- 사진: 내 구글 드라이브 **‘제주여행 사진’** 폴더에 1일차·2일차·3일차로 나눠 저장
- 한마디·바뀐 기록: 구글 시트 **‘제주여행 기록’**에 한 줄씩 저장
- 여행이 끝나면 이 시트와 사진 폴더로 추억 피드를 만들 수 있어요.

전체 순서는 **① 저장 서버 만들기 → ② 주소 붙여 넣기 → ③ GitHub에 올리기 → ④ 단톡방에 공유**예요. 처음 한 번만 하면 돼요 (20분 정도).

---

## ① 저장 서버 만들기 (구글 Apps Script)

> 회사 구글 계정은 외부 공유가 막혀 있는 경우가 많아요. **개인 Gmail 계정**으로 하는 걸 추천해요.

1. 컴퓨터에서 https://script.google.com 에 들어가 **새 프로젝트**를 눌러요.
2. 왼쪽 위 ‘제목 없는 프로젝트’를 눌러 이름을 `제주여행 서버`로 바꿔요.
3. 편집기에 있는 내용을 모두 지우고, 이 폴더의 `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(Ctrl/Cmd + S)해요.
4. 위쪽 함수 목록에서 **setup**을 고르고 **▶ 실행**을 눌러요.
   - ‘권한 검토’ → 내 계정 선택 → **고급 → 제주여행 서버(으)로 이동(안전하지 않음)** → **허용**
   - 내가 만든 코드라 이 경고가 떠도 괜찮아요.
   - 아래 실행 로그에 ‘준비 끝!’이 보이면 성공이에요. 드라이브에 시트와 사진 폴더가 생겼어요.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

## ② 주소 붙여 넣기

`config.js` 파일을 메모장(또는 텍스트 편집기)으로 열어서:

```js
API_URL: 'https://script.google.com/macros/s/여기에-복사한-주소/exec',
ADMIN_PIN: '1016',   // 관리자 비밀번호. 원하면 바꾸세요.
```

이렇게 고치고 저장해요. 주소를 비워 두면 **연습 모드**(내 휴대폰에만 저장)로 동작해요.

## ③ GitHub에 올려서 인터넷 주소 만들기

1. https://github.com/new 에서 저장소 이름을 `jeju-trip`으로 하고 **Public**을 고른 뒤 **Create repository**를 눌러요.
2. 다음 화면의 **uploading an existing file**을 눌러요.
3. 이 폴더 안의 **파일과 `icons` 폴더를 전부** 끌어다 놓아요. (`index.html`이 맨 위에 있어야 해요.)
4. 아래 **Commit changes**를 눌러요.
5. 저장소의 **Settings → Pages**로 가서 Branch를 **main / (root)**로 고르고 **Save**를 눌러요.
6. 1~2분 뒤 위쪽에 주소가 나와요: `https://내아이디.github.io/jeju-trip/`

## ④ 단톡방에 공유하고 설치하기

- 주소를 단톡방에 올려요.
- 각자 링크를 열어 이름을 적고, 홈 화면의 **‘휴대폰에 앱으로 설치하기’** 안내를 따라 해요.
  - 갤럭시: 삼성 인터넷/크롬 → 메뉴 → ‘홈 화면에 추가’ (버튼 하나로 될 때도 있어요)
  - 아이폰: **사파리**에서 공유 버튼 → ‘홈 화면에 추가’
  - 카톡 안에서 열었다면 먼저 ‘다른 브라우저로 열기’(아이폰은 ‘Safari로 열기’)를 눌러요.

## 알림은 이렇게 동작해요

- 일정을 바꾸면 바꾼 사람 화면에 **‘카톡으로 알리기’** 버튼이 떠요. 누르면 카톡 단톡방으로 바로 보낼 수 있어요.
- 앱을 열면(또는 열어 둔 채로 30초마다) 새 소식을 확인해서, 위쪽 종 모양과 띠로 보여 줘요.

## 나중에 고치고 싶을 때

- 일정 기본 내용은 `data.js`, 설정은 `config.js`에서 고쳐요.
- GitHub 저장소에서 파일을 열고 연필 아이콘으로 고친 뒤 저장해요.
- 파일을 고친 뒤에는 `sw.js` 맨 위의 `VERSION` 숫자를 하나 올려 주세요 (예: `jeju-v2`). 그래야 휴대폰이 새 버전을 받아요.
- `Code.gs`를 고쳤다면 Apps Script에서 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 눌러요. (주소는 그대로예요.)

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱의 뼈대 |
| `app.js` | 모든 화면과 동작 (시작·홈·일정·지도·사진·한마디·새 소식·설치 안내·관리자) |
| `styles.css` | 색과 글씨 크기 |
| `data.js` | 23곳 일정 기본 데이터 |
| `config.js` | 서버 주소, 관리자 비밀번호 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 휴대폰 설치용 설정 |
| `apps-script/Code.gs` | 구글 시트·드라이브 저장 서버 (GitHub에는 안 올려도 돼요) |

## 알아 두면 좋은 점

- 링크를 아는 사람은 누구나 볼 수 있고 글을 남길 수 있어요. 링크는 단톡방에만 공유해 주세요.
- 한마디는 쓴 휴대폰에서만 고치거나 지울 수 있어요.
- 사진은 올리기 전에 휴대폰에서 알맞은 크기(긴 변 1600px)로 줄여서 빠르게 올라가요. 원본 화질이 필요하면 따로 공유해 주세요.
- 사진의 **찍은 시간**은 줄이기 전에 따로 읽어서 시트 `photos` 탭의 `takenAt` 칸에 저장해요. 파일 이름도 찍은 시간으로 시작해서 드라이브에서 시간순으로 정렬돼요.
  - 사진에 시간 정보가 없으면 파일 날짜로 대신하고, 이때 `takenGuess` 칸에 TRUE가 표시돼요.
  - 위치(`lat`, `lng`)는 휴대폰이 위치 정보를 남겨 둔 경우에만 저장돼요. 아이폰은 사진을 고를 때 ‘옵션 → 위치’를 켜야 남아요.
